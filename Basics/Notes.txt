Warn Functions:
A function is a named block of reusable code that accepts inputs (arguments), does work, and optionally returns a value. 
Functions are first-class in Python: they can be assigned to variables, passed as arguments, and returned from other functions.

Info Function arguments
1) Positional arguments: def f(a, b):
2) Default arguments: def f(x=10):
3) Keyword arguments: can call f(a=1, b=2)
4) Var-positional (*args): collects extra positional args as a tuple
5) Var-keyword (**kwargs): collects extra keyword args as a dict
6) Keyword-only args (after *): def f(a, *, b): — b must be passed by name

Warn Class:
A class is a blueprint for creating objects (instances) grouping state (attributes) and behavior (methods). 
Python uses dynamic typing and runtime objects.
In class, functions = methods = [function(self)], variables = attributes  
### "self" represents the instance being initialized.

Implement Python protocols to behave like built-ins:
1) Construction/Utils: __init__, __new__, __repr__, __str__ 
2) Comparison: __eq__, __lt__, __hash__
3) Container protocol: __len__, __getitem__, __setitem__, __contains__
4) Iteration: __iter__, __next__
5) Context manager: __enter__, __exit__
6) Callable objects: __call__
### "__init__" just initializes an object that has already been created. Define atttributes/variables for class inside "__init__".
