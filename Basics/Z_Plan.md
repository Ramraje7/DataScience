# 📆 **30-Day DevOps + Data Engineering Transition Plan**

*(30 Sept – 1 Nov)*

---

## 🔹 **Week 1 (Sept 30 – Oct 6): Core Foundations**

**Goal:** Get strong in **Python, Linux, Git** → daily hands-on scripts.

* **Day 1 (Sept 30): Python Basics**

  * Data types, loops, functions.
  * Hands-on: Write script to read logs & count errors.

* **Day 2: Python for Data Handling**

  * JSON, CSV, API requests (`requests` library).
  * Project: Fetch weather API data → save to CSV.

* **Day 3: Python with Pandas**

  * DataFrames, cleaning, transformations.
  * Project: Clean messy CSV (nulls, duplicates, etc.).

* **Day 4: Linux Essentials**

  * File system, permissions, `grep`, `awk`, `sed`.
  * Task: Parse system logs with Linux + Python.

* **Day 5: Git & GitHub**

  * Branching, merge, pull requests.
  * Task: Push Day 2–4 scripts to GitHub repo.

* **Day 6: SQL Basics**

  * Joins, Group By, Window functions.
  * Project: Load CSV into SQLite/Postgres and query.

* **Day 7 (Sun): Review & Mini-Project**

  * Project: **Python ETL** → Extract (API), Transform (Pandas), Load (Postgres).
  * Push project with README to GitHub.

  * Multi-stage builds, DockerHub push.
  * Task: Optimize Dockerfile for ETL script.

* **Day 10: Kubernetes Basics**

  * Pods, Deployments, Services.

  * ConfigMaps, Secrets, Ingress.

* **Day 12: CI/CD – Jenkins**

  * Install Jenkins locally.
  * Task: Pipeline for “build → push Docker → deploy to K8s”.

* **Day 13: CI/CD – GitHub Actions**

  * Write GitHub workflow (YAML).
  * Task: Same pipeline using GitHub Actions.

* **Day 14 (Sun): Mini-Project**

  * **Flask App + Docker + CI/CD + K8s**.
  * Push project to GitHub.
